# 前線 Frontline

二戰俯視角的多人推線對戰，用瀏覽器就能玩。2–4 人各自為戰（空位可以補電腦），一局最多 10 分鐘。
玩法參考《螞蟻部落之戰（Ants Warriors）》的出兵推線，加上鋼鐵雄心的戰線與領土概念。

美術參考板：<https://claude.ai/artifact/AJaa4gs7joV5yFJCEfA132>

## 玩法

- **大本營＋堡壘**：每個人開局有一座大本營（裡面有 3 個步兵班）和兩座小堡壘，地圖上還有無主的中立堡壘。堡壘會自己開砲，裡面每 1 人口駐軍火力 +4%（最多 +50%）。
- **買兵與駐軍**：在自己的據點買兵，兵先駐紮在據點裡、會慢慢回血。據點有容量上限（大本營 24、大型堡壘 16、小堡壘 12 人口），總兵力上限 60 人口。**養兵費**：野外的兵每人口每秒 0.06；據點裡囤的兵越多，每人口越貴（囤 20 人口每秒約 5），逼你把兵派出去用。
- **派兵**：點據點選好兵種和數量（沒選＝全部），從據點拖到道路或另一個據點放開，部隊會走最短路過去；拖曳途中經過的據點會變成必經點，拖曳時看得到路線預覽。一次派很多兵會依序間隔出門，前排（戰車、步兵）先走、砲兵和醫療兵殿後，集中火力又不會擠成一團。
- **調度**：點自己的部隊選整隊，可以拖曳或點地圖改目的地、撤退（回最近的自己據點、途中不開火、跑比較快，進去後回血），也可以設定「到了／佔下來後進駐」。
- **攻破與佔領**：把堡壘打到 0 就變成廢墟，裡面的駐軍會衝出來守在門口；任何人的部隊在旁邊站 3 秒（沒有敵軍在場）就能佔領。剛佔下的堡壘 15 秒後才開始產錢。
- **領先者懸賞**：堡壘數唯一最多的人會被懸賞，攻破他的堡壘賞金加倍、擊殺他的部隊賞金 ×1.5，鼓勵大家一起打領先的人。
- **四張地圖**：四方要塞（2–4 人，環形＋十字路）、大河之戰（2–4 人，只有三座橋能過河）、沙漠綠洲（2–3 人，搶中央綠洲要塞）、山口突破（2 人，兩座山把戰場切成三條路）。房主在作戰室選地圖，也可以選隨機。
- **兵種剋制**：步兵班 → 反戰車砲 → 戰車 → 步兵班；機槍組壓制步兵。砲兵射程 200、有範圍傷害，但 70 以內打不到、血很少：戰車（裝甲讓砲彈傷害減半）、機槍組、空降兵、轟炸機都剋砲兵。
- **新兵種**：狙擊手（射程 190 一槍一個，剋機槍、砲兵、醫療兵，怕裝甲車）、火焰兵（近距離燒一片，剋擠在一起的步兵、碉堡）、裝甲車（跑最快的輕裝甲，搶點追殺步兵，怕反戰車砲和戰車）、防空砲車（跟著部隊打飛機）。兵種分成步兵、車砲、支援三個分頁。
- **工兵**：近身爆破堡壘和工事（攻城主力），也會修理自己的據點、工事和車輛、加快工事施工；駐紮在據點裡會順便修據點。
- **醫療兵**：跟著部隊走，同時幫附近 3 個步兵類部隊回血，自己不攻擊、前面有敵人會停下來。
- **塔防工事**：點自己據點旁路邊的 ＋ 蓋機槍碉堡、反戰車砲陣地、防空砲。**要施工 12–15 秒**，施工中只有 25% 血、不會開火；附近每個工兵 +100% 速度（最多 4 倍），據點裡駐紮的工兵也會幫忙。
- **堡壘改建**：自己的堡壘（大本營以外）可以花錢改建，改建要 10 秒，被攻破就變回標準堡壘，外觀會跟著變：
  - 砲台 $150：對地火力 +60%、射程 +30，駐軍上限 -4
  - 兵營 $120：駐軍上限 +8、駐軍回血加倍、在這裡買兵 85 折，火力 -20%
  - 補給站 $140：收入 +2.5/秒，血量 -20%
  - 防空要塞 $110：對空火力 ×3、對空射程 +80
  - 野戰醫院 $130：附近 160 內的己方步兵每秒回 6 血、駐軍回血加倍
- **隨機事件**（開局約 70 秒後開始，每隔 45–75 秒一次）：補給空投（搶補給箱 +$200）、暴風雨（飛機不能起飛、射程 -20%）、砲擊彈幕（紅圈 2 秒後落彈，敵我不分）、援軍抵達（堡壘最少的人免費多 3 支部隊）、燃料短缺（車輛速度減半）、戰功懸賞（擊殺賞金加倍）。
- **空軍**（開局 30 秒後）：轟炸機可以炸地圖上任何一條路；運輸機把兩班空降兵丟到敵人後方。防空砲會把飛機打下來。
- **出局**：大本營被打爆就出局，他所有的堡壘都變成無主，誰先佔領就是誰的。
- **勝負**：活到最後的人贏；10 分鐘到了就比擁有的堡壘數，平手再比大本營剩餘血量。
- **結算的勢力變化圖**：每 5 秒記一次每個人的勢力（部隊＋工事＋據點的價值）、兵力、據點數，結算畫面可以切換三種看法；滑過或用手指按住圖會顯示那個時間點每個人的數值，出局的人在出局時間畫 ✕，下面也有數據表。
- **提示字**：大提示字顯示在畫面上方，點一下就關掉。
- **音效與配樂**：全部即時合成。背景是軍樂進行曲，戰況越危急越激烈；佔領、失守、勝利、戰敗都有號角。iPhone 開著靜音開關也會有聲音。

### 手機（iOS／Android）

首頁有簡單的遊戲規則（電腦在右邊，手機按「遊戲規則」打開）。手機切到背景或記憶體不夠時，瀏覽器可能把遊戲畫面收回去造成黑屏；遊戲會自己偵測並在幾秒內重建畫面，也可以按畫面中間的「重新載入戰場」。重建兩次以上會自動改用相容性比較好的 Canvas 模式。

手機要橫著玩：左邊是選到的據點、空軍、升級，右邊是兵種（左半邊點一下買一支、右半邊「派」點一下選要派出幾支），地圖在中間。用手指從據點拖到目的地就派兵；點路邊的 ＋ 蓋工事，叫空軍時先點按鈕再點道路。**兩指縮放／移動戰場、單指拖空地移動畫面**，左下角「全圖」縮回來；放大後點部隊和據點會準很多。

- **Android**：用 Chrome 開，按「全螢幕橫向遊玩」，或在遊戲裡點右上角的全螢幕圖示。
- **iPhone**：Safari 不支援網頁全螢幕。點「分享」→「加入主畫面」，從主畫面的「前線」圖示開啟，就是沒有網址列的全螢幕。
- LINE、FB 內建的瀏覽器不能全螢幕，請改用 Chrome 或 Safari 開。

### 電腦操作

| 按鍵 | 功能 |
|---|---|
| 點自己的據點（或 Tab） | 選據點 |
| 1–9、0、- | 在選到的據點買兵：步兵班、機槍組、狙擊手、火焰兵、裝甲車、戰車、反戰車砲、防空砲車、砲兵、工兵、醫療兵（按住 Shift 點按鈕一次買 5 支） |
| Shift + 數字、點「派」 | 多選一支要派出的（右鍵點「派」減一；A 全選） |
| 從據點拖曳到道路／據點 | 派兵（經過的據點是必經點） |
| 點自己的部隊 | 選整隊；再拖曳或點地圖改目的地 |
| R | 選到的部隊撤退 |
| 滾輪／拖曳空地 | 縮放／移動戰場 |
| E | 切換「到了／佔下來後進駐」 |
| B / P，再點地圖上的道路 | 轟炸機、空降部隊（右鍵或 Esc 取消） |
| Z / X / C | 升級火力、裝甲、後勤 |
| 點路邊的 ＋ | 蓋工事 |
| M | 靜音 |
| N | 開關背景配樂 |

## 自己跑起來

需要 Node.js 20 以上。

```bash
npm install
npm run dev
```

打開 <http://localhost:5173>。同一個 Wi-Fi 的朋友可以用 `http://你的電腦IP:5173` 加入（終端機會列出網址）。

- 「單人練習」：自己對兩個電腦。
- 「建立房間」：拿到 4 碼代碼，把代碼或邀請連結傳給朋友。

### 正式架設（讓外網的朋友玩）

```bash
npm install
npm run build   # 打包前端到 client/dist
npm start       # 一個埠同時提供網頁和連線（預設 2567，可用 PORT 環境變數改）
```

任何能跑 Node.js 的主機都可以。repo 裡有 `render.yaml`（Render）和 `Dockerfile`。

## 專案結構

```
shared/src/index.ts     兵種、工事、空軍、升級的數值（平衡都改這裡）
shared/src/map.ts       四張地圖（據點、道路、地形）與道路幾何、路口距離
server/src/game/Battle.ts  所有遊戲規則（伺服器權威，前端只負責畫）
server/src/game/Bot.ts     電腦玩家（也代管斷線玩家）
server/src/rooms/BattleRoom.ts  房間、大廳、斷線重連
client/src/game/BattleScene.ts  Phaser 戰場畫面
client/src/game/fx.ts      爆炸、曳光彈、煙霧等特效
client/src/game/textures.ts 所有圖都是程式畫的（不需要圖檔）
client/src/game/sound.ts   Web Audio 合成音效與軍樂配樂（不需要音檔）
client/src/ui/             首頁、作戰室、對局介面
```

## 測試

```bash
MATCH_SECONDS=90 npm start   # 本機測試用：把一局縮短成 90 秒（正式環境不要設）
npm test        # 兵種剋制、買兵駐軍、派兵與調度、撤退、養兵費、工事施工、堡壘改建、隨機事件、懸賞、空軍、四張地圖的電腦混戰
npm run typecheck
```

## 技術

TypeScript 全端：Phaser 4（畫面）、Colyseus 0.18（多人連線、房間、狀態同步）、Vite（前端打包）。
伺服器每秒模擬 20 次，前端只送指令（出兵、蓋工事、升級、叫空軍），所以沒辦法作弊，斷線重新整理也能回到同一局。
