WWII 即時戰線推進

前線

FRONTLINE

買兵進駐堡壘、拖曳派兵、搶下中央要塞。2–4 人連線，或單人對電腦。

怎麼玩

  1. 目標打爆其他人的大本營。10 分鐘到了，堡壘最多的人贏。
  2. 買兵點自己的據點，從下方滑出的面板買兵。兵會待在據點裡回血，但囤越多養兵費越貴。
  3. 派兵從據點拖到道路或別的據點就出發，拖曳經過的據點會變成必經點。沒選數量就是全部派出。
  4. 調度點自己的部隊選整隊，再拖曳或點地圖換目的地，也可以撤退回據點回血。
  5. 佔領把堡壘打到 0 變廢墟，派兵在旁邊站 3 秒就是你的；附近還有敵軍時佔領會暫停。佔下後可以改建成砲台、兵營、補給站、防空要塞或野戰醫院。
  6. 剋制步兵 → 反戰車砲 → 戰車 → 步兵；狙擊手剋機槍和砲兵；裝甲車剋步兵；工兵拆堡壘最快；醫療兵幫步兵回血。
  7. 其他路邊的 ＋ 可以蓋工事（要施工）；30 秒後能叫轟炸機和空降；不時有隨機事件；堡壘最多的人會被懸賞。
  8. 手機橫著玩；兩指縮放、拖空地移動戰場。
